문제 1. 창고 부품 번호의 검증숫자

정수론 · 논증20점

발명교육센터 창고의 부품에는 6자리 번호 d1d2d3d4d5d6가 붙어 있다. 각 자리는 0부터 9까지의 숫자이고, 0으로 시작하는 번호도 있다.

입력 실수를 찾기 위해 검증숫자 c를 하나 붙인다. 먼저 S = 1·d1 + 2·d2 + 3·d3 + 4·d4 + 5·d5 + 6·d6을 계산하고, c는 S를 7로 나눈 나머지(0~6)로 정한다. 부품의 최종 코드는 d1⋯d6c의 7자리이다.

컴퓨터는 코드를 입력받으면 앞의 6자리로 S를 다시 계산해서 입력된 c와 다르면 “오류”라고 알린다. 입력 실수가 있었는데도 c와 같으면 오류를 탐지하지 못한다. (아래에서 c 자리는 항상 정확히 입력된다고 하자.)

(1) 번호 314159의 검증숫자 c를 구하고, 최종 코드를 쓰시오. [4점]
(2) 번호의 한 자리만 다른 숫자로 잘못 입력된 경우, 컴퓨터가 오류를 탐지하지 못하는 경우를 모두 찾고 그 이유를 설명하시오. 탐지하지 못하는 실제 번호 예를 하나 드시오. [6점]
(3) 이웃한 두 자리의 숫자를 서로 바꿔 입력했다(두 숫자는 다르다). 컴퓨터가 오류를 탐지하지 못하는 조건을 구하고 증명하시오. 바꾼 위치에 따라 조건이 달라지는지도 답하시오. [6점]
(4) 000000부터 999999까지의 모든 번호 중, 첫째 자리와 둘째 자리를 바꿔 입력했을 때 번호가 바뀌는데도 오류를 탐지하지 못하는 번호는 모두 몇 개인지 구하시오. [4점]
문해력 포인트. 이 문제의 핵심 문장은 “입력 실수가 있었는데도 c와 같으면 탐지하지 못한다”입니다. 즉 번호는 바뀌었지만 S를 7로 나눈 나머지가 같아지는 경우를 찾는 문제입니다. 그러므로 번호가 바뀔 때 S가 얼마나 변하는지를 식으로 쓰고, 그 변화량이 7의 배수가 되는 조건을 찾으면 됩니다.

(1) 검증숫자 계산

  1. S = 1·3 + 2·1 + 3·4 + 4·1 + 5·5 + 6·9 = 3 + 2 + 12 + 4 + 25 + 54 = 100.
  2. 100 = 7 × 14 + 2이므로 c = 2입니다.

c = 2, 최종 코드 3141592

(2) 한 자리 오류

  1. i번째 자리 숫자가 d에서 d′로 바뀌면 S는 i(d′ − d)만큼 변합니다. 다른 자리는 그대로이기 때문입니다.
  2. 컴퓨터가 탐지하지 못하는 경우는 나머지가 같은 경우이므로, 변화량 i(d′ − d)가 7의 배수일 때입니다.
  3. i는 1~6이므로 7과 서로소입니다(7은 소수입니다). 곱 i(d′ − d)가 7의 배수이고 i가 7의 배수가 아니므로, d′ − d가 7의 배수여야 합니다.
  4. 0~9의 서로 다른 두 숫자의 차는 1~9이고, 그중 7의 배수는 7뿐입니다. 따라서 차가 7인 경우, 즉 0↔7, 1↔8, 2↔9 (양방향 6가지)입니다. 이것이 자리에 관계없이 탐지 못하는 한 자리 오류의 전부입니다.
  5. 실제 예: 번호 250481에서 셋째 자리 0을 7로 잘못 입력해 257481이 되었다고 합시다. 원래 S = 2 + 10 + 0 + 16 + 40 + 6 = 74, 잘못된 번호는 S = 2 + 10 + 21 + 16 + 40 + 6 = 95. 74 = 7×10 + 4, 95 = 7×13 + 4로 나머지가 같으므로 탐지하지 못합니다.

차가 7인 숫자쌍 0↔7, 1↔8, 2↔9로 바뀐 경우

자주 하는 실수. “한 자리 오류는 항상 탐지된다”고 단정하는 것. 7이 소수라는 사실과 i가 7보다 작다는 사실만으로는 d′ − d가 7일 가능성이 남습니다.

(3) 이웃한 두 자리의 교환

  1. 이웃한 두 자리 i, i+1의 숫자를 a, b라 하면, 교환 전 두 자리의 기여는 i·a + (i+1)·b입니다.
  2. 교환 후는 i·b + (i+1)·a입니다.
  3. (후) − (전) = (i+1)a + i·b − i·a − (i+1)b = a − b. 즉 변화량은 위치 i와 무관하게 a − b입니다.
  4. 탐지하지 못하려면 a − b가 7의 배수여야 합니다. a ≠ b이므로 두 숫자의 차가 7이어야 하고, 0~9에서는 {0, 7}, {1, 8}, {2, 9} 세 쌍뿐입니다.

이웃한 두 숫자의 차가 7일 때(0과 7, 1과 8, 2와 9). 교환 위치와 무관

(4) 개수 세기

  1. (d1, d2)로 가능한 순서쌍은 (0,7), (7,0), (1,8), (8,1), (2,9), (9,2)의 6가지입니다. (3)에서 첫째·둘째 자리도 이웃이므로 같은 조건이 적용됩니다.
  2. 나머지 네 자리 d3~d6은 각각 10가지이므로 104 = 10000가지입니다.
  3. 곱의 법칙: 6 × 10000 = 60000.

60000개

스스로 점검. 가중치를 1, 2, …, 6 대신 모두 1로 바꾸면 이웃한 교환 오류는 어떻게 될까요? 또 7 대신 11로 나누면 한 자리 오류가 항상 탐지될까요?

문제 3. 포장지 접기

기하 · 접기20점

가로가 8 cm, 세로가 6 cm인 직사각형 포장지 ABCD가 있다. 꼭짓점 A는 왼쪽 아래, B는 오른쪽 아래, C는 오른쪽 위, D는 왼쪽 위이다.

꼭짓점 C가 꼭짓점 A에 정확히 겹치도록 접었더니, 접는 선이 변 AB 위의 점 E와 변 DC 위의 점 F를 지났다.

(1) 접는 선 EF 위의 점 E에서 A까지의 거리와 C까지의 거리가 같음을 설명하시오. [4점]
(2) 선분 AE의 길이를 구하시오. [6점]
(3) 접었을 때 종이가 두 겹으로 겹친 부분의 넓이를 구하시오. [5점]
(4) 접는 선 EF의 길이를 구하시오. [5점]
문해력 포인트. “C가 A에 정확히 겹치도록 접는다”는 말을 수학으로 바꾸면 접는 선은 두 점 A, C를 잇는 선분의 수직이등분선이라는 뜻입니다. 접으면 점이 접는 선에 대해 거울에 비친 위치로 옮겨지기 때문입니다.

(1) AE = EC인 이유

  1. 접는 선에 대해 C와 A는 서로 대칭입니다. 접는 선 위의 점은 접을 때 움직이지 않으므로 E는 그대로이고, C가 A로 옮겨집니다.
  2. 접기 전의 선분 EC가 접은 뒤 선분 EA와 정확히 겹치므로 길이가 같습니다. 따라서 EA = EC입니다.

(2) AE의 길이

  1. AE = x cm라 하면 (1)에 의해 EC = x이고, E가 AB 위에 있으므로 EB = 8 − x입니다.
  2. 삼각형 EBC는 B가 직각인 직각삼각형입니다(직사각형의 꼭짓점). 피타고라스 정리에서 EC² = EB² + BC²이므로 x² = (8 − x)² + 6².
  3. 전개하면 x² = 64 − 16x + x² + 36이고, x²이 양쪽에서 소거되어 16x = 100, x = 25/4입니다.

AE = 25/4 cm (6.25 cm)

검산. EB = 8 − 25/4 = 7/4. EB² + BC² = 49/16 + 36 = 625/16 = (25/4)²로 EC² 와 같습니다.

(3) 겹친 부분의 넓이

  1. 접는 선 EF를 기준으로 오른쪽 사각형 EBCF가 왼쪽으로 접힙니다. 접힌 사각형은 A를 한 꼭짓점으로 하고, 원래 종이의 왼쪽 부분 AEFD와 겹치는 부분이 두 겹이 됩니다.
  2. 겹치는 부분은 삼각형 AEF입니다. 접힌 사각형의 세 점 E, A, F가 이루는 삼각형이 원래 종이 위에 그대로 포개지기 때문입니다.
  3. 삼각형 AEF에서 밑변을 AE = 25/4로 잡으면, F는 변 DC 위에 있으므로 F에서 AB까지의 높이는 BC와 같은 6입니다.
  4. 넓이 = ½ × 25/4 × 6 = 75/4.

75/4 cm² (18.75 cm²)

(4) 접는 선 EF의 길이

  1. F도 접는 선 위의 점이므로 (1)과 같은 이유로 AF = FC입니다. DF = y라 하면 FC = 8 − y이고, 직각삼각형 ADF에서 AF² = 6² + y²입니다.
  2. AF = FC에서 36 + y² = (8 − y)² = 64 − 16y + y²이므로 16y = 28, y = 7/4입니다.
  3. F에서 AB에 내린 수선의 발을 G라 하면 AG = DF = 7/4, FG = 6입니다. EG = AE − AG = 25/4 − 7/4 = 9/2.
  4. 직각삼각형 EGF에서 EF² = 6² + (9/2)² = 36 + 81/4 = 225/4, 따라서 EF = 15/2.

EF = 15/2 cm (7.5 cm)

자주 하는 실수. (3)에서 겹친 부분을 “사각형 EBCF의 넓이” 또는 “직사각형의 절반”으로 착각하는 것. 직사각형의 절반(24)은 EBCF의 넓이이지 겹친 부분이 아닙니다.
스스로 점검. 대각선 AC의 길이는 10입니다. EF = AC × 3/4임을 확인하고, 이 비가 우연이 아닌 이유를 닮음으로 설명할 수 있을까요?

예: n = 7의 처음 상태 (모두 꺼짐)
(1) n = 6일 때 모든 전구를 켤 수 있음을 보이시오. [3점]
(2) n = 7일 때는 어떤 작업을 하더라도 모든 전구를 켤 수 없음을 증명하시오. [6점]
(3) 전구의 번호를 3으로 나눈 나머지에 따라 세 그룹으로 나눌 때, 작업을 해도 변하지 않는 성질을 찾아 설명하시오. [6점]
(4) 모든 전구를 켤 수 있는 n을 모두 구하고 증명하시오. [5점]
문해력 포인트. “같은 작업은 몇 번이고 반복할 수 있다”가 중요합니다. 같은 작업을 두 번 하면 원래대로 돌아가므로, 각 작업은 하느냐(1) 안 하느냐(0)만 의미가 있습니다. 이렇게 바꾸면 경우의 수가 크게 줄어듭니다.

(1) n = 6

  1. 1~3번 전구에 작업을 한 번 하면 1, 2, 3번이 켜집니다.
  2. 4~6번 전구에 작업을 한 번 하면 4, 5, 6번이 켜집니다. 두 작업 후 6개가 모두 켜집니다.

작업 2번(1~3번, 4~6번)으로 가능

(2) n = 7이 불가능한 이유

  1. 작업 ①은 1~3번, ②는 2~4번, ③은 3~5번, ④는 4~6번, ⑤는 5~7번 전구를 바꿉니다. 작업 ⓚ를 하면 1, 하지 않으면 0이라 하고 x1, …, x5로 씁니다.
  2. 각 전구가 켜지려면 그 전구를 바꾸는 작업의 횟수가 홀수여야 합니다.
  3. 1번 전구는 ①만 바꾸므로 x1 = 1입니다.
  4. 2번 전구는 ①, ②가 바꾸므로 x1 + x2가 홀수이고, x1 = 1이므로 x2 = 0입니다.
  5. 3번 전구는 ①, ②, ③이 바꾸므로 1 + 0 + x3가 홀수, x3 = 0입니다.
  6. 4번 전구는 ②, ③, ④: 0 + 0 + x4가 홀수, x4 = 1입니다.
  7. 5번 전구는 ③, ④, ⑤: 0 + 1 + x5가 홀수, x5 = 0입니다.
  8. 6번 전구는 ④, ⑤: 1 + 0 = 1로 홀수이므로 만족합니다.
  9. 그런데 7번 전구는 ⑤만 바꾸므로 x5가 홀수여야 합니다. 그러나 앞에서 x5 = 0으로 정해졌으므로 모순입니다.

n = 7에서는 불가능

자주 하는 실수. “여러 가지로 해 봤는데 안 된다”는 서술은 점수를 받지 못합니다. 작업을 0/1로 두고 한 줄씩 값을 정해 모순에 이르는 과정을 쓰세요.

(3) 변하지 않는 성질 (불변량)

  1. 번호를 3으로 나눈 나머지가 1, 2, 0인 전구를 각각 A, B, C 그룹이라 합니다.
  2. 이웃한 세 전구의 번호는 연속한 세 수이므로, 3으로 나눈 나머지가 서로 다른 세 값을 한 번씩 가집니다. 즉 한 번의 작업은 A, B, C 그룹에서 정확히 하나씩 바꿉니다.
  3. 바뀌는 전구가 켜지든 꺼지든, 한 번의 작업에서 각 그룹의 “켜진 전구의 개수”는 +1 또는 −1로 변합니다. 따라서 세 그룹의 켜진 개수는 모두 홀짝이 함께 바뀝니다.
  4. 처음에는 세 그룹 모두 켜진 개수가 0(짝수)입니다. 그러므로 세 그룹의 켜진 전구 개수의 홀짝은 항상 서로 같습니다.

불변량: 세 그룹의 켜진 전구 수의 홀짝이 항상 같다

(4) 가능한 n

  1. 모든 전구가 켜진 상태라면 각 그룹의 켜진 개수는 그 그룹의 전구 수입니다.
  2. n = 3k+1이면 그룹의 크기가 (k+1, k, k)로 홀짝이 같을 수 없습니다. n = 3k+2이면 (k+1, k+1, k)로 역시 같을 수 없습니다. 따라서 불가능합니다.
  3. n = 3k이면 1~3번, 4~6번, …, (3k−2)~3k번에 작업을 한 번씩 하면 모두 켜집니다 (k번의 작업).
  4. 검증: n = 7은 (3, 2, 2)로 불가능하며 (2)와 일치합니다. n = 6은 (2, 2, 2)로 가능합니다.

n이 3의 배수일 때만 가능

스스로 점검. 연속 세 개가 아니라 연속 네 개를 바꾸는 작업이라면 불변량을 어떻게 바꿔야 할까요? 가능한 n은 무엇일까요?
채점 기준 (20점)

문제 5. 계단을 오르는 로봇

규칙성 · 점화식20점

계단 오르기 로봇은 한 걸음에 1칸 또는 2칸만 오를 수 있다. n칸짜리 계단을 맨 위까지 오르는 방법의 수를 an이라 하자. 걸음의 순서가 다르면 다른 방법이다. 예를 들어 3칸 계단은 (1, 1, 1), (1, 2), (2, 1)의 3가지이므로 a3 = 3이다.

로봇의 모터가 과열되는 것을 막기 위해, 이제부터는 2칸 걸음을 연달아 두 번 할 수 없다는 규칙을 추가한다. 이 규칙을 지키며 n칸을 오르는 방법의 수를 bn이라 하자.

(1) a1, a2, a3, a4, a5를 구하시오. [4점]
(2) an, an−1, an−2 사이의 관계를 이유와 함께 설명하고, a8을 구하시오. [5점]
(3) b1, b2, b3, b4, b5를 구하고, (1)의 값과 달라지는 이유를 설명하시오. [5점]
(4) bn을 앞의 값들로 계산하는 규칙을 찾아 이유를 설명하고, b8을 구하시오. [6점]
문해력 포인트. “2칸 걸음을 연달아 두 번 할 수 없다”는 규칙은 2칸 걸음 다음에는 반드시 1칸 걸음이 와야 한다는 뜻입니다. 단, 2칸 걸음이 맨 끝에 오거나, 1칸 걸음 사이에 2칸이 홀로 있는 것은 괜찮습니다. 이 한 줄이 (4)의 점화식을 결정합니다.

(1) 작은 경우 직접 세기

  1. a1 = 1 (1), a2 = 2 (1+1, 2), a3 = 3.
  2. 4칸: (1,1,1,1), (1,1,2), (1,2,1), (2,1,1), (2,2)로 a4 = 5.
  3. 5칸: 걸음 수가 5, 4, 3인 경우를 나누어 세면 1 + 4 + 3 = 8. a5 = 8.

1, 2, 3, 5, 8

(2) 점화식과 a₈

  1. n칸을 오르는 방법을 마지막 걸음으로 나눕니다. 마지막이 1칸이면 앞의 n − 1칸을 오르는 방법이 an−1가지입니다.
  2. 마지막이 2칸이면 앞의 n − 2칸을 오르는 방법이 an−2가지입니다.
  3. 두 경우는 겹치지 않고, 모든 방법이 둘 중 하나에 속하므로 an = an−1 + an−2 (n ≥ 3)입니다.
  4. a6 = 8 + 5 = 13, a7 = 13 + 8 = 21, a8 = 21 + 13 = 34.

a₈ = 34

(3) 2칸 연속 금지: b₁ ~ b₅

  1. b1 = 1, b2 = 2 (1+1, 2), b3 = 3 (1+1+1, 1+2, 2+1). 여기까지는 2칸이 연속될 수 없어 an과 같습니다.
  2. 4칸에서 (2, 2)는 2칸 걸음이 연속되므로 제외됩니다. 따라서 b4 = 5 − 1 = 4입니다: (1,1,1,1), (1,1,2), (1,2,1), (2,1,1).
  3. 5칸의 a5 = 8가지 중 2칸이 연속인 (1,2,2), (2,2,1)을 제외하면 6가지입니다: (1,1,1,1,1), (1,1,1,2), (1,1,2,1), (1,2,1,1), (2,1,1,1), (2,1,2). b5 = 6.

b₁ ~ b₅ = 1, 2, 3, 4, 6

(1)과 달라지는 이유: 4칸부터는 (2, 2)처럼 2칸이 연속되는 걸음이 생기기 때문입니다. 규칙이 그런 방법들을 제외합니다.

(4) 점화식과 b₈

  1. 마지막 걸음으로 나눕니다. 마지막이 1칸이면 앞의 n − 1칸은 규칙을 지키는 어떤 방법이든 가능하므로 bn−1가지입니다.
  2. 마지막이 2칸이면 그 바로 앞 걸음은 반드시 1칸이어야 합니다(2칸이 연달아 올 수 없습니다). 따라서 끝부분은 (…, 1, 2)이고, 이 둘이 오르는 3칸을 제외한 앞의 n − 3칸은 규칙을 지키는 어떤 방법이든 되므로 bn−3가지입니다. (n = 3이면 앞이 0칸이므로 b0 = 1로 둡니다.)
  3. 두 경우는 겹치지 않고 빠짐이 없으므로 bn = bn−1 + bn−3.
  4. 확인: b4 = b3 + b1 = 3 + 1 = 4, b5 = b4 + b2 = 4 + 2 = 6 (직접 센 값과 일치).
  5. b6 = 6 + 3 = 9, b7 = 9 + 4 = 13, b8 = 13 + 6 = 19.

bₙ = bₙ₋₁ + bₙ₋₃, b₈ = 19

자주 하는 실수. a의 점화식에서 b도 bₙ = bₙ₋₁ + bₙ₋₂라고 단정하는 것. 이 식은 마지막이 2칸일 때 앞이 (n−2)칸 중 “1칸으로 끝나는 경우만” 허용되어야 한다는 조건을 무시합니다. (b₄ = 5로 잘못 나옵니다.)
스스로 점검. b₈ = 19가지 중 2칸 걸음이 정확히 0번, 1번, 2번, 3번인 경우는 각각 몇 가지일까요? 합이 19가 되는지 확인해 보세요. (정답: 1, 7, 10, 1)
