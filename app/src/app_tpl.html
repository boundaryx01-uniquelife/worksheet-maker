자동 설계

실전 난이도 구성에 맞춰 문항을 고릅니다. 영역은 겹치지 않게 분산하고, 학습 기록에서 정답률이 낮은 영역을 우선합니다.

커스텀 문제지

문항마다 영역·난이도를 정하거나 문제를 직접 지정합니다. 지정하지 않으면 조건에 맞는 문제를 무작위로 뽑습니다.

문제 은행

AI로 변형 문제 만들기

고른 문제를 바탕으로 Claude가 새 문제를 만듭니다. 만들면서 정답을 코드로 계산해 확인하게 하지만, 사람이 한 번 더 풀어 보고 쓰세요. 문제는 은행에 추가해야 시험지에 들어갑니다.

문제 추가·내보내기 (JSON)

새 문제를 JSON으로 붙여 넣으면 은행에 추가되고, 이 브라우저에 저장됩니다. 필수 항목: id, title, topic, tag, level(중하·중·중상·상), body, sol, rubric([{t,p}]), ah(서술칸 mm).

학습 기록

해설·채점 모드에서 [기록 저장]을 누르면 쌓입니다. 이 기록이 자동 설계의 약점 우선에 쓰입니다. (이 브라우저에만 저장)

출력 창에서 대상을 "PDF로 저장"으로 고르면 PDF가 됩니다. 용지 A4, 배율 100%. (Claude 안에서 열었다면 버튼으로 받은 HTML 파일을 크롬에서 여세요.)
